# 入力欄(PiyoTextField)

文字を入れる欄。面は入力欄の役割(`SurfaceRole.Field`)で、スタイルが描く。

## 書き方

```kotlin
var name by remember { mutableStateOf("") }
PiyoTextField(name, { name = it }, placeholder = "名前")
PiyoTextField(query, { query = it }, placeholder = "探す", leading = { PiyoIcon(Icons.Search, null) })
PiyoTextField(memo, { memo = it }, singleLine = false, minHeight = 96.dp)
```

- 値は文字列か `TextFieldValue`(カーソルや選んだ範囲も扱う)
- 幅は使う側が決める(横いっぱいなら `Modifier.fillMaxWidth()`、ボタンと並べるなら `Modifier.weight(1f)`)
- 案内は、入力の揃え方(`textAlign`)に合わせて置き、1行の欄では折り返さない
- 文字の色は、`textStyle` に色があればそれを使い、なければ `contentDefault`
- `leading` は左、`trailing` は右に置く(検索の印、単位、消すボタンなど)。色は控えめな文字色
- 空のときは `placeholder` を控えめな文字色を .55 に薄めて出す(入力した文字と見間違えない)

## 見た目

| スタイル | 塗り | 影 | フォーカス中 |
|---|---|---|---|
| Glass | 主な色を面に 10% 混ぜる(`glass.field.tint`)。タグ(3%)より濃い。しゃぼんのように枠の色の並びを主な操作に使うプリセットは、主な色の薄い塗りに、その並びをごく薄く混ぜる | 内側だけ。上に主な色の濃い影(下へ 1.5、ぼかし 3)、下の縁に白い光り。外の影は付けない | 塗りを薄め、ボタンと同じ枠のグラデーション(太さ 1) |
| Plain | 主な色(しゃぼんは枠の色の並びの真ん中)を面に混ぜる | なし。`ringShadow` の細い枠 | 塗りを薄め、枠を主な色に |
| 無効(両方) | ふつうの入力欄のまま、全体を不透明度 .45 に(`control.disabledOpacity`) | 同じ | なし |

## 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 塗り | タグより濃く | 依頼者の希望。押す部品(タグ)と、書き込む場所を見分けやすくする |
| 影 | 内側の影で少し凹ませ、浮かせる外の影は付けない | 依頼者の希望。ボタンは浮いて「押せる」、入力欄は凹んで「書き込める」と、手ざわりで分ける |
| フォーカス | 塗りを薄め、ボタンと同じ枠のグラデーション(太さ 1) | いま書いている欄がひと目で分かる。最初は主な色の太い枠(1.5)にしたが、ほかの部品と揃わず強すぎたので、ボタンの枠に合わせた(依頼者の指摘) |
| 無効 | 無効のボタンと同じく、ふつうの入力欄を薄くする | 灰色や点線の枠も試したが、ほかの部品の無効と見え方を揃えることにした(依頼者の決定)。薄くする量はボタンと同じ .45 |
| しゃぼんの塗り | 主な色のごく薄い塗りに、枠の色の並びを薄く混ぜる | 青1色だとしゃぼんに見えず、並びを濃く流すとカラフルすぎた(依頼者の指摘) |
| 文字の色 | 入力した文字は `contentDefault`、案内と左右の印は `contentMuted` | ボタンの面(`contentSelected`)と分けた。長い文を読みやすく |
